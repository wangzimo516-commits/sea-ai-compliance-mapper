# SEA AI Compliance Mapper

Tracking AI-related data protection and security requirements across Southeast Asia.

## Countries covered (in progress)
- [ ] Vietnam — Personal Data Protection Law (effective 2026)
- [ ] Singapore — AI Verify Framework / PDPA
- [ ] Malaysia — PDPA + Anti-Fake News Act
- [ ] Indonesia — PDP Law
- [ ] Thailand — PDPA + EEC Sandbox
- [ ] Philippines — Data Privacy Act

## What this repository will contain
- Country-by-country compliance checklists
- Links to primary regulatory sources
- A Python script to map AI application types to applicable regulations
